# FG-TIDA Meeting Minutes

This repository holds the official minutes and slides for FG-TIDA meetings, including the virtual "Interregnum" preparation meetings and the in-person Focus Group meetings.

Each meeting has its own folder containing the minutes (`minutes.md`) and the accompanying slide deck (`.pptx`).

- Once a PR is merged, update the index table above with a link to the new file.
